Other changes
- The engine is a copy at `engine/geo_score_calc.py` + `engine/weights.json`. The default weights path now points to the file beside the script. Gate level effects are logged as gate actions, not as anchor overrides (batch case study items 2-3). New optional JSON fields: `downgrade_reason` (criterion) and `evidence_type` (check).
- `common.py` points at `engine/`. `verify_prompts.py` adds the selftest, a check of the standard's 26 effective-weight tables, and v2.1 backward compatibility (rules=v2.1). `rerun_testrun.py` is new.
- `source_gaps.md` (Appendix C) marks the resolved items and the data notes (#44 = #43, the mismatched 55-58 renders, whitepaper_doc untested).

Not changed
- Weights and stage multipliers. No fix required them. U5 for software was considered and rejected (fix 17).
- Pilot statistics in the standard are the v2.1 pilot as published. Under v2.2 rules the same pilot JSONs score differently; see `testrun_rerun_v2.2.md` for the engine effect on the 62 test-run files.
