When to use this type

An article-style page on se.com that is not on the blog and is not a news release — a perspective piece, a trends page, an explainer in a hub. If it sits on blog.se.com, use the blog type instead; if it announces something, use news.

Why it has no criteria of its own

It has no fixed furniture. A blog is expected to carry takeaways and a byline; a release has a dateline and an About block. An editorial page has only the shared qualities, so the ten carry the whole 100 points and “answer up front” is weighted highest of any type, at 16.
