RUN THE APP (Python 3.9+; the venv is already built on the original laptop,
rebuild it with the commands in PROJECT_MAP.md on a new one):
  cd ~/"Documents/geo scoring project/2-streamlit-app/geo-score-app"
  ./.venv/bin/streamlit run app.py
  Opens at http://localhost:8501 — first load takes about 20 seconds.
  Needs a Gemini API key in .streamlit/secrets.toml (not in the repo).
  The Replay tab needs no key.

DEMO WITHOUT THE APP
  Open the file for your page type in 9-prompts-by-content-type/GEO v2.2/,
  paste it into Copilot, give the page URL.
